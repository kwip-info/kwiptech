Security and trust

Kwip products are built around private deployment, auditable control boundaries, and minimal data movement.

Product security architecture

Kwip separates product control planes from customer data planes wherever possible. Digest runs inside the customer's network and does not send documents to Kwip. PyScoped runs in the customer's application process and syncs operational metadata to the platform without object payloads.

Digest runtime boundary

Digest runs as a self-hosted container in the customer's network. The Kwip platform can expose documentation, release channels, image digests, and update access, but extraction requests and customer documents stay in the customer's data plane. Digest does not require generative AI, GPUs, or hosted document processing APIs.

Release and supply chain

Private image distribution

Digest images are distributed through a private registry to licensed customers with explicit access.

Pinned runtime versions

Production deployments should pin immutable image digests rather than floating tags.

SBOM and license checks

Release automation verifies Python package licenses and generates image metadata for review.

Vulnerability scanning

Container releases are scanned before publication so dependency and base-image issues are visible.

Data residency

Digest documents are processed by the customer-hosted runtime, not uploaded to Kwip. PyScoped application data remains in the customer's infrastructure; its sync path sends structural metadata such as actor, object type, timestamp, operation, and chain hash. Object data payloads such as before_state and after_state are deliberately excluded from sync.

PyScoped sync security

TLS encryption

All communication between the sync agent and the management plane is encrypted in transit via TLS.

HMAC-SHA256 signatures

Every sync batch is signed with HMAC-SHA256 using a key derived from your API key. The management plane verifies the signature before accepting any data.

Hash-chained audit trail

Each audit entry includes a hash of the previous entry, creating a tamper-evident chain. The management plane verifies chain integrity on every sync.

Content hashing

Each batch includes a SHA256 hash of its contents, ensuring nothing was modified in transit independent of the transport layer.

Digest runtime hardening

Container isolation

Digest is designed to run with restricted container privileges such as dropped capabilities and no-new-privileges.

Controlled scratch space

Operators can mount temporary extraction storage explicitly and avoid persistent customer-document storage in Kwip systems.

No GPU dependency

Digest does not require GPU access or a hosted generative AI service to perform extraction.

Customer-controlled network

Customers decide where the runtime can listen and what internal systems can call it.

PyScoped compliance invariants

PyScoped is the authorization and audit product in the Kwip catalog. Its core framework enforces invariants for registered objects, identity, access decisions, versioning, revocation, and audit traceability.
