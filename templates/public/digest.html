Digest by Kwip

Universal Document Extraction Runtime

A private, self-hosted API for extracting normalized text and metadata from business documents, images, PDFs, and archives.

Request pilot access Read docs

Runs locally

Docker deployment inside the customer's network.

No hosted AI

No generative model, GPU, or paid document API.

No document storage

Customer files stay in customer-controlled runtime storage.

Broad formats

Text, markup, office, PDF, OCR images, and ZIP archives.

What Digest provides

Stable extraction API

Normalized text, metadata, page details, warnings, and extractor provenance behind one HTTP contract.

Commercial maintenance boundary

Curated open-source extractors packaged with compatibility tests, updates, and release documentation.

Control-plane only platform fit

Kwip can expose docs, image tags, and update access without routing customer documents through the platform.

Economic model

Digest is priced for distribution and maintenance rights, not page volume. Customers provide the compute, so the claim is near-zero marginal compute cost and no customer-document storage cost.
