No surprise overage

Paid overage starts off. When you enable it, you choose a monthly spending cap. Queries that exceed your allowance and cap are refused before records are delivered.

{% elif screen == 'developers' %}

Built for integration

One API.
Evidence included.

Discover datasets, inspect their schemas, and retrieve bounded pages of records with source and revision metadata.

1. Explore the catalog

No token is required for dataset metadata.

curl {{ market_origin }}/api/v2/datasets

2. Create a scoped key

Sign in to your account and create a read key. Keep it in your service’s secret store. Each key expires and can be revoked independently.

3. Retrieve records

Set a maximum credit cost and a unique idempotency key. Reuse that key when retrying the exact same request.

curl {{ market_origin }}/api/v2/datasets/DATASET/query \
  -H "Authorization: Bearer $KWIP_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: your-unique-request-id" \
  -d '{"limit":25,"max_credits":25}'

Use the returned cursor for the next page, with a new idempotency key. Cursors pin the dataset snapshot for up to 24 hours.

Connect an agent

Agents can request a connection code, ask you to approve it, then receive a scoped token. They never need your browser password.

POST /api/v2/device/start
{"name":"Research assistant",
 "scopes":["datasets:read"]}

Display the returned verification URL and user code. Poll /api/v2/device/poll with the device code at the returned interval. Stop on denial or expiry.

This is KWIP’s device-linking protocol, not an OAuth or MCP authorization endpoint.

Publish repeatably

KWIP operators register a versioned dataset schema and an approved source. Source-scoped publishing keys push bounded batches with idempotency keys. Validate with a dry run before applying.

POST /api/v2/operator/datasets/DATASET/
     sources/SOURCE/batches
{"dry_run":true,"items":[...]}
